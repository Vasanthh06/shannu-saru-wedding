Drop 20 couple photos in this folder, named:

  01.jpg  02.jpg  03.jpg ... 20.jpg

Optional:
  vasanth.jpg   -> the photo shown in the "Made with ♥ by Vasanth" card

Tips
- JPEG, about 1600 px on the long edge, quality ~78 (keeps the album under ~4 MB).
- The grid uses the `size` hint in CONFIG.photos, so a portrait photo in a
  tall slot and a landscape photo in a wide slot look best.
- Any missing file simply shows the frame number instead of a broken image.

Also drop in a photo for the venue if you have one — name it venue.jpg and
point CONFIG.venue.photo at it (optional).
